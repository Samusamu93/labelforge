# Security Policy / Politica di sicurezza

## Reporting a vulnerability / Segnalare una vulnerabilità

**EN:** If you find a security issue in LabelForge, please **do not open a public issue**.
Instead, report it privately via GitHub Security Advisories
(*Security → Report a vulnerability*) on the repository, or open a normal issue only for
non-sensitive matters. We'll respond as soon as possible.

**IT:** Se trovi un problema di sicurezza in LabelForge, **non aprire una issue pubblica**.
Segnalalo in privato tramite GitHub Security Advisories (*Security → Report a vulnerability*)
sul repository. Per problemi non sensibili puoi usare una issue normale. Rispondiamo appena possibile.

## Scope / Ambito

LabelForge is a desktop/CLI tool that sends label data to printers over the local network or USB.
It has no server component and stores settings/templates locally. Note that the app sends **raw**
data to printers; use it only with printers you trust on your network.

LabelForge invia dati a stampanti in rete locale o USB, non ha componenti server e salva
impostazioni/modelli in locale. L'app invia dati **raw** alle stampanti: usala solo con stampanti
fidate sulla tua rete.

## Supported versions / Versioni supportate

Only the latest release is supported. / È supportata solo l'ultima release.

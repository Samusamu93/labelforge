Stampa etichette ZPL su stampanti Zebra — app desktop + CLI

Progetta le etichette visivamente, compila i campi o scansionali con un lettore di codici a barre, e stampa via rete o USB. Editor drag & drop, anteprima live con barcode e QR reali. Nessuna dipendenza a pagamento.

✨ Cosa fa

🖨️ Rete o USB

Stampa via porta di rete 9100, stampante Windows per nome (qualsiasi porta) o device USB su Linux/Mac.

🎨 Editor visuale

Trascina, ridimensiona e allinea gli elementi con snap alla griglia. Anteprima live con codici reali.

🔠 Molti codici

Testo, Code128, Code39, Code93, EAN‑13, QR Code e DataMatrix. Misure in mm, 203/300 dpi.

⌨️ Scansiona e stampa

Stampa automatica dopo la scansione. Import CSV per stampe in blocco (una etichetta per riga).

🧩 Campi dinamici

Campi come testo, menu a tendina o liste con quantità (es. una etichetta per taglia/variante).

💾 Comodo

Storico con ristampa, ricerca modelli, tema chiaro/scuro, scorciatoie e impostazioni ricordate.

🚀 Come iniziare

Scarica l'app per il tuo sistema dalla pagina delle Release, oppure avviala dai sorgenti:

npm install  →  npm start

Compatibile con le stampanti Zebra ZPL (testata su ZD410). Documentazione completa nel README.

🔌 Prova l'API di stampa

Con il print server attivo (nell'app: ⚙️ → Print server, oppure node cli.js serve), compila e invia una richiesta di stampa. La chiamata `curl` si aggiorna in tempo reale sotto.

Nota: se apri questa pagina via HTTPS, il browser può bloccare le chiamate a http://localhost (mixed content). In tal caso copia il comando curl o usa la pagina in locale. API completa: docs/INTEGRATION.md.

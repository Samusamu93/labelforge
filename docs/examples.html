LabelForge — Esempi di template

Modelli JSON pronti da copiare in templates/ o da importare dall'editor.

← Home · GitHub

Ogni template è un file JSON con misure in mm. I campi {{...}} diventano input nell'app (testo, menu a tendina o liste con quantità). Tipi di elemento disponibili: text, barcode128, code39, code93, ean13, datamatrix, qrcode, box, line.

Etichetta prodotto 51 × 25 mm

Titolo, sottotitolo e codice a barre Code128. Adatta a scaffali e magazzino.

{
  "name": "prodotto-51x25",
  "dpi": 203, "width_mm": 51, "height_mm": 25, "tear_off": 30,
  "elements": [
    { "type": "text", "x_mm": 3, "y_mm": 2, "height_mm": 3.5, "text": "{{titolo}}" },
    { "type": "text", "x_mm": 3, "y_mm": 7, "height_mm": 2.2, "text": "{{sottotitolo}}" },
    { "type": "barcode128", "x_mm": 3, "y_mm": 11, "bar_height_mm": 9, "text": "{{codice}}" }
  ]
}

Spedizione 102 × 152 mm

Destinatario, indirizzo e barcode dell'ordine. Formato 4×6 pollici.

{
  "name": "spedizione-102x152",
  "dpi": 203, "width_mm": 102, "height_mm": 152, "tear_off": 30,
  "elements": [
    { "type": "text", "x_mm": 5, "y_mm": 6, "height_mm": 6, "text": "{{destinatario}}" },
    { "type": "text", "x_mm": 5, "y_mm": 16, "height_mm": 4, "text": "{{indirizzo}}" },
    { "type": "text", "x_mm": 5, "y_mm": 24, "height_mm": 4, "text": "{{citta_cap}}" },
    { "type": "barcode128", "x_mm": 5, "y_mm": 120, "bar_height_mm": 22, "text": "{{ordine}}" }
  ]
}

Varianti prodotto 70 × 40 mm select + quantità

Categoria come menu a tendina e taglie con quantità: stampa una etichetta per ogni taglia scelta. Include testo, barcode e QR.

{
  "name": "varianti-70x40",
  "dpi": 203, "width_mm": 70, "height_mm": 40, "tear_off": 30,
  "field_meta": {
    "categoria": { "type": "select", "label": "Categoria", "options": ["STANDARD","PREMIUM","OUTLET"] },
    "taglia": { "type": "multi-qty", "label": "Taglie (quantità)", "options": ["XS","S","M","L","XL"] }
  },
  "elements": [
    { "type": "text", "x_mm": 3, "y_mm": 2, "height_mm": 4, "text": "{{prodotto}}" },
    { "type": "text", "x_mm": 3, "y_mm": 8, "height_mm": 3, "text": "Cat: {{categoria}}  Taglia: {{taglia}}" },
    { "type": "barcode128", "x_mm": 3, "y_mm": 19, "bar_height_mm": 12, "text": "{{sku}}" },
    { "type": "qrcode", "x_mm": 48, "y_mm": 16, "magnification": 4, "text": "{{sku}}" }
  ]
}

Asset / inventario 50 × 30 mm QR + DataMatrix

Etichetta cespite con QR (link/scheda) e DataMatrix per la marcatura compatta.

{
  "name": "asset-50x30",
  "dpi": 203, "width_mm": 50, "height_mm": 30, "tear_off": 30,
  "elements": [
    { "type": "text", "x_mm": 3, "y_mm": 2, "height_mm": 3.5, "text": "{{nome}}" },
    { "type": "text", "x_mm": 3, "y_mm": 7, "height_mm": 2.5, "text": "ID: {{id}}" },
    { "type": "qrcode", "x_mm": 3, "y_mm": 11, "magnification": 4, "text": "{{id}}" },
    { "type": "datamatrix", "x_mm": 30, "y_mm": 11, "magnification": 5, "text": "{{id}}" }
  ]
}

📄 Stampa in blocco da CSV

Per stampare tante etichette (una per riga), importa un CSV: le intestazioni devono corrispondere ai campi {{...}} del modello. Dall'app, il pulsante ⬇ CSV di esempio genera un file già con le colonne giuste per il modello selezionato.

title,subtitle,code
Vite M6x20,Confezione 100pz,8012345000019
Dado M6,Confezione 200pz,8012345000026
Rondella M6,Confezione 500pz,8012345000033

Esempi pronti nella cartella examples/ del repository (product-51x25.csv, product-variants-70x40.csv).

💡 Per usare i template: salva un file .json nella cartella templates/ (oppure Editor → Importa .json). Puoi anche partire da uno di questi e modificarlo visivamente trascinando gli elementi nell'anteprima.
